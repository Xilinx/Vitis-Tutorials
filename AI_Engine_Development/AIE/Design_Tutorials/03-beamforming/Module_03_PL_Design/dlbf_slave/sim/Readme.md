# Summary

This simulation design builds on the IP generated by using the Makefile in the parent directory, that is, `dlbf_slave`. The design uses the following blocks:

1. AXI4 LITE VIP
2. AXI4 Stream Master VIP
3. Reset blocks
4. dlbf_slave IP
