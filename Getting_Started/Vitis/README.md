# Vitis Introduction and Getting Started Tutorial

***Version: Vitis 2025.2***

Welcome to Vitis Getting Started!

This tutorial discusses the important concepts of the Vitis tool flow, building the components, building the design and running the design on the hardware and hardware emulation with two different ways of using pre-built Vitis Common Linux Binaries.
One flow showcases using Petalinux Common Images for Versal devices and another showcases using Embedded Development Flow common images for Versal Gen2 devices.

1. [Versal_w_PetaLinux](./Versal_w_PetaLinux/README.md)
2. [Versal_w_EDF](./Versal_w_EDF/README.md)

Please read the tutorial in the same order as listed here to better understand the Vitis tool flow. At the end of each section, a link to the next chapter is included. Below 

1. [Understanding the Vitis Tool Flow](./Vitis_ToolFlow.md)
2. [Getting Started with Designing using the Vitis Tool](./Design_Overview.md)
3. [Running the Hardware Emulation](./Running_the_Hardware_Emulation.md)
4. [Running the design on a Evaluation Board](./Hardware_Run.md)

## Prerequisites
    
Please refer README.md of each design for more details on the setup requirement.

Ensure you have the following installed on your machine:

* Vitis tools
* Versal Evaluation Kits
* Commom Image
