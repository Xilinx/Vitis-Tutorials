# Vitis Subsystem Simulation

The feature Vitis Subsystem Simulation enables user to simulate AI Engine + PL designs in a RTL testbench environment.
By running the AI Engine simulation encapsulated in a VSS component, the interaction between AI Engine PLIO and custom RTL can be analyzed and verified without having to go through the full system emulation flow.

This feature is demonstrated using Vivado XSIM as part of the [Versal Vitis Subsystem Flow](../../Design_Tutorials/02-Versal_Vitis_Subsystem_Flow).

For details, see [Simulate AIE+PL in XSIM with RTL testbench](../../Design_Tutorials/02-Versal_Vitis_Subsystem_Flow/vss/cosim/README.md).

**Note**: This is an Early Access feature and can be subject to change. Please contact your local FAE for information and details.
